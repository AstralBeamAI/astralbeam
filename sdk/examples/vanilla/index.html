Every paragraph on this page is crimson, italic, and prefixed with a 🔥 by hostile global styles, and there are rules targeting the widget's own elements and class names with !important.

What to check

  1. Shadow DOM isolation: the widget's header and "Hello world" bubble in the sidebar ignore all of the global styles — they render with the widget's own styles from inside its shadow root.
  2. Slot projection: the crimson 🔥 paragraph inside the widget's dashed "slotted host content" box is light-DOM markup owned by this page (see the sidebar div in index.html); it is projected into the widget's <slot> and keeps host styling.
  3. Lazy loading: the network tab shows the React widget module loading as a separate chunk after the page.
  4. Mount / unmount: the button below disposes and remounts the widget through the handle returned by mountAstralBeamChat.
