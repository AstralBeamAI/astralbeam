# Coding agents

Ask your coding agent to use the [AstralBeam skill](/agent-skills/astralbeam/SKILL.md) in your app's repository.

First, [connect a model and create an API key](/docs/start/quickstart#1-prepare-your-agent). Keep the key in your backend's environment, never in the prompt.

You can also install the skill from [astralbeam.ai](https://astralbeam.ai) with a tool that supports [website discovery](https://github.com/cloudflare/agent-skills-discovery-rfc), or from the [skill's repository directory](https://github.com/AstralBeamAI/astralbeam/tree/main/skills/astralbeam).
